Neste projeto estou acompanhando as aulas da Alura do curso: Formação Aprenda a programar em Java com Orientação a Objetos.
No primeiro commit foi a criação do projeto em si, criação da classe Main e Flmes, criação de métodos e atributos;
O segundo commit foram as primeiras modificações de métodos muito extensos como: a modificação do "mediaDasAvaliacoes" e algumas modificações "exibeFichaTecnica" e um exception no método "avalia";
o terceiro commit foi a simplificação do método avalia e remoção de verbosidades do mesmo;
O quarto commit foi a criação do Package "br.com.alura.screenmatch.modelos.Filmes" e adição da classe Filmes na mesma e modificações nas permissões dos métodos;
O quinto remoção de alguns Getters e Setters que eu não quero que o usuário tenha acesso;
O Sexto foi a criação de uma classe abstrata chamada Titulo e passando toda a paternidade da classe filmes para ela e passando a herança dela para as classes Filmes e Series e criando as exclusividades de ambas;
